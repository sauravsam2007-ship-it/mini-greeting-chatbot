# Mini Greeting Bot

My first mini-project written in C language.

## About
This is a simple interactive console program that greets
the user by name and accepts a short question.

## Features
- User name input
- Personalized greeting
- Accepts a short question
- Displays a basic response

## Technologies Used
- C Language
- GCC Compiler
- Visual Studio Code

## How to Run

Compile:
gcc main.c -o greeting

Run on Windows:
.\greeting.exe
